# HANDOFF: бесплатный запас LLM для ботов

Обновлено: 2026-10-24. Новая сессия читает этот файл первым.

## Цель
Боты (в первую очередь Reels Radar) не встают, когда у Claude кончился недельный лимит. Решение Некита: вариант «средний», бесплатная модель только там, где замена не ломает результат. Это запас на случай лимита, не замена Claude.

## Что сделано и работает
- Модуль `tools/llm_fallback/llm_fallback.py` (только stdlib), 14 тестов в `tests/`. Запуск: `cd reels-radar && .venv/bin/python -m pytest ../tools/llm_fallback/tests -q`.
- Порядок: Claude, при лимите и `free_ok=True` цепочка FreeLLMAPI (`FREELLM_MODELS`, по умолчанию `openai/gpt-oss-120b,ministral-14b-latest`), проверка JSON и типов по схеме с повтором. Если не ответила ни одна модель, поднимается исходная ошибка лимита, и конвейер встаёт на паузу, как раньше.
- Подключено в Reels Radar: `claude.py` (`run_claude_free`), `vision.py` (`classify`), `cards.py` (пометка). При запасе: тема не доверяется (папка IG или «Разное»), `reason=free:router:<модель>`, в карточке строка «⚠ Разобрано бесплатной моделью без кадров, тему выбери сам». Кадры при запасе не используются.
- Тесты Reels Radar: 125 зелёных (`cd reels-radar && .venv/bin/python -m pytest -q`).
- Живой вызов проверен 23.10: при недоступном claude `classify` ответил через gpt-oss (и отдельно через ministral).
- Ночной launchd Reels Radar уже стоит (night 03:00 `run --limit 60`, digest вс 19:00, bot). Ночь пока простаивает: очередь пуста, новые рилсы приходят только ручным экспортом Instagram.
